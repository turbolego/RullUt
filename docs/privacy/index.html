Personvernerklæring for RullUt

Sist oppdatert: 29. juli 2026

RullUt ("appen") er utviklet av Turbolego. Denne personvernerklæringen forklarer hvordan vi håndterer dine data når du bruker appen.

1. Data vi samler inn

RullUt samler ikke inn, lagrer eller deler personopplysninger. Appen er designet slik at dine data blir på din enhet.

Følgende data håndteres lokalt på din enhet og sendes ikke til oss:

  • Posisjon (GPS) — brukes kun for å vise din plassering på kartet og som utgangspunkt for ruteplanlegging. Posisjonen behandles lokalt og deles ikke med tredjeparter.
  • Rutesøk — start- og målpunkt for ruteplanlegging behandles kun i sanntid og lagres ikke.

2. Tredjepartstjenester

RullUt bruker følgende eksterne API-er for å fungere. Disse mottar kun data som er nødvendig for å utføre din forespørsel:

  • Norgeskart.no (Geonorge WMS) — offentlig karttjeneste fra Kartverket. Viser tilgjengelighetsdata (rullestolruter og universell utforming). Ingenting av din posisjon eller identitet sendes.
  • OpenFreeMap — gratis bakgrunnskart. Ingen data om deg sendes.
  • Overpass API (OpenStreetMap) — offentlig API for å hente vei- og toalettdata. Kun koordinater i sanntid sendes.
  • Valhalla (OpenStreetMap.de) — offentlig ruteplanlegger. Kun start- og målpunkt sendes for å beregne ruten.
  • Kartverket Stedsnavn — offentlig API for stedsøk. Kun søketeksten din sendes.

Alle disse tjenestene er offentlige og gratis API-er. Ingen av dem mottar personlig identifiserbar informasjon om deg.

3. Informasjonskapsler (cookies)

RullUt bruker ikke informasjonskapsler eller lignende sporingsteknologi.

4. Lagring av data

RullUt lagrer kun dine innstillinger (valgt bakgrunnskart og aktive kartlag) lokalt på enheten via Android DataStore. Disse dataene deles ikke med noen.

5. Tredjeparts overføringer

Vi overfører ikke dine data til tredjeparter. Vi bruker ingen analyseverktøy, ingen annonsenettverk og ingen sporingsbiblioteker.

6. Dine rettigheter

Siden vi ikke samler inn personopplysninger, har vi ingen slike data om deg å slette eller eksporterere. Posisjonstilgang kan du når som helst slå av i enhetens innstillinger under Innstillinger → Apper → RullUt → Tillatelser.

7. Endringer i denne erklæringen

Ved vesentlige endringer vil vi oppdatere denne siden og versjonen av appen. Sjekk denne siden jevnlig for oppdatert informasjon.
